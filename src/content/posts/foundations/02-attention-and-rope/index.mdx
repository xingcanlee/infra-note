上一篇里的 RMSNorm 与 SwiGLU 全部是**逐词元独立计算**：把「猫 坐在 垫 上」四个字打乱成「上 垫 坐在 猫」，第 3 号向量独自穿过前馈网络后依然产出完全一样的结果。语言模型如果只靠线性层与门控前馈，本质上还停留在「词袋」阶段——词元之间没有任何上下文交换。

**自注意力（Self-Attention）**负责打通横向信息流，让当前词元按内容相关性去加权读取历史词元；而 **旋转位置编码（RoPE）** 则用一把极其精巧的二维几何尺子，把「绝对位置」悄无声息地折叠进点积里的「相对距离」。到了长上下文场景，再由 **YaRN** 把高、中、低频通道分层拉长，防止视野一翻倍就失焦。

读完这一篇，你可以亲手回答以下 4 个问题：

- 4 个词元如何通过 $Q$、$K$、$V$、因果掩码和 Softmax 完成一次严格防偷看的上下文读取？
- 为什么点积必须除以 $\sqrt{d_k}$，而不是直接用原始内积进 Softmax？
- RoPE 怎样靠二维旋转让点积只依赖相对距离 $n - m$？`rotate_neox`、`rotate_gptj` 与 DeepSeek-V4 的尾切片各有何工程差异？
- 为什么朴素线性插值（PI）会糊掉近邻词序，而 YaRN 用分频斜坡掩码与 `mscale` 就能平稳外推到 `128K`？

## 先看一个例子：4 个词元如何通过 Q/K/V 检索

把注意力想象成一次图书检索：每个词元同时生成三个向量——自己正在找什么的**查询（Query, $Q$）**、自己身上挂着供别人匹配的**索引标签（Key, $K$）**，以及匹配成功后真正被搬运走的信息内容**值（Value, $V$）**。

我们来看一句 4 个词元的话：`["猫", "坐在", "垫", "上"]`（位置索引 $t = 0, 1, 2, 3$），取单头特征维度 `d_k = 4`（此时缩放因子 $\sqrt{d_k} = \sqrt{4} = 2$，口算极简）。点击图 1 的单步控制条，观察 `QK^T` 打分如何被因果掩码拦截并在归一化后汇聚为上下文输出。

逐行追踪图 1 最后两个位置（$t=2$ 与 $t=3$）的数值变化：

1. **缩放打分（$S = QK^T / \sqrt{4}$）**：第 $t=2$ 行（「垫」）原本和四个位置的点积除以 2 之后是 `[0.5, 1.0, 0.5, 1.0]`——注意最后一个 `1.0` 来自未来的 $t=3$（「上」），如果直接算权重就会偷看答案！
2. **因果掩码（$+ M_{\text{triu}}$）**：生成式模型只能看自己及左侧历史，因此在计算 Softmax 之前，先把行号小于列号（严格上三角）的所有未来位置加上 $-\infty$。于是 $t=2$ 行的分数变成 `[0.5, 1.0, 0.5, -inf]`。
3. **逐行 Softmax 归一化**：经过 $e^{-\infty} = 0$，未来权重被彻底清零。$t=2$ 行变成 `[0.2741, 0.4519, 0.2741, 0.0000]`（最关注 $t=1$「坐在」）；$t=3$ 行位于句尾，可以看全 4 个词，权重为 `[0.3112, 0.1888, 0.1888, 0.3112]`（同时锁定「猫」和自身「上」）。
4. **加权聚合输出（$O = P \cdot V$）**：把 Softmax 权重乘上对应行的 $V$ 并相加，得到 $O_2 = [0.4111, 0.5889, 0.4111, 0.2259]$ 与 $O_3 = [0.4056, 0.2832, 0.5000, 0.4056]$。这步过后，位置 3 的向量已经融合了句首主语「猫」的语义。

## 因果多头自注意力与 1/sqrt(d_k) 缩放推导

把 4 词元的直觉写回张量形式，先列出完整形状与符号表：

| 符号              | 含义                                                   | 张量形状   | 所在角色                                   |
| :---------------- | :----------------------------------------------------- | :--------- | :----------------------------------------- |
| $T$               | 序列长度（例图中 $T = 4$）                             | 标量       | 词元数                                     |
| $H,\,d_k$         | 注意力头数与每头特征维                                 | 标量       | 多头划分：$d_{\text{model}} = H \cdot d_k$ |
| $Q,\,K,\,V$       | 查询、键、值矩阵（单头切片）                           | `[T, d_k]` | 线性投影输出                               |
| $M_{\text{triu}}$ | 因果掩码矩阵（上三角 $-\infty$，下三角含对角线为 $0$） | `[T, T]`   | 防未来信息泄露[^ds_causal]                 |

单头缩放点积因果自注意力的计算公式为[^vaswani2017]：

$$
\text{Attention}(Q, K, V) = \text{Softmax}\!\left(\frac{Q K^T}{\sqrt{d_k}} + M_{\text{triu}}\right) V
$$

为什么非除以 $\sqrt{d_k}$ 不可？假设 $q$ 与 $k$ 的每个分量互独立、均值为 `0`、方差为 `1`，那么单维乘积 $q_j k_j$ 的均值为 `0`、方差为 $\text{Var}(q_j k_j) = \mathbb{E}[q_j^2]\mathbb{E}[k_j^2] = 1$。将 $d_k$ 个独立同分布项相加后，方差线性累加：

$$
\text{Var}(q \cdot k) = \sum_{j=1}^{d_k} \text{Var}(q_j k_j) = d_k \quad\Longrightarrow\quad \text{Var}\!\left(\frac{q \cdot k}{\sqrt{d_k}}\right) = \frac{d_k}{(\sqrt{d_k})^2} = 1
$$

当头维度从玩具例子的 `4` 放大到主流模型的 `64` 或 `128` 时，未缩放点积的典型幅度会膨胀到 $\pm\sqrt{64} = \pm 8$ 甚至更大。Softmax 对极端大数极度敏感：一旦某个位置领先几分，指数函数就会把概率权重压成近似 `[1.0, 0.0, 0.0, ...]` 的尖刺，导致其余位置梯度接近零而难以更新。乘以 $1/\sqrt{d_k}$ 恰好把输入 Softmax 的方差拉回稳定的 `1.0`（在 vLLM 的 `DeepseekAttention` 中对应 `self.scaling = self.head_dim**-0.5`[^vllm_dsv2_attn]）。

**多头（Multi-Head）的直觉**：如果全句只用一套 $Q/K$ 打分，就像整间图书馆只允许按「书名拼音」排一次序，很难同时兼顾「主谓呼应」「指代消解」和「标点匹配」。多头把 $d_{\text{model}}$ 拆成 $H$ 组独立的 `[T, d_k]` 子空间并行做注意力和加权求和，最后再把 $H$ 份结果沿着最后一维拼回 `[T, H * d_k]` 并乘一次输出投影 $W_O$——相当于让多位专注不同角度的检索员各找各的，最后汇总成一句话。

## 旋转位置编码（RoPE）：用二维旋转把绝对坐标写成相对偏移

纯粹的自注意力虽然能交换上下文，但依然是**置换等变**的：同时把 $Q, K, V$ 的行按相同顺序打乱，输出也只是跟着打乱，模型分不清谁紧贴谁。要注入词序，Su 等人在 2021 年提出了 **RoPE（Rotary Position Embedding）**[^su2021]：不再把位置向量直接**加**到词向量上，而是按词元位置 $m$ 对 $Q$ 和 $K$ 做**正交旋转**。

先看二维平面上的单对坐标 $(x_0, x_1)$：位置为 $m$ 的词元转过角度 $m\theta_i$，旋转矩阵 $R_{\theta_i, m}$ 与 $d$ 维整体旋转频率 $\theta_i$ 定义为：

$$
R_{\theta_i, m} = \begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix}, \qquad \theta_i = \text{base}^{-2i/d},\quad i \in \left\{0, 1, \dots, \frac{d}{2}-1\right\}
$$

由于二维旋转矩阵满足正交转置性质 $R_{\theta_i, m}^T = R_{\theta_i, -m}$ 且角度可加 $R_{\theta_i, a} R_{\theta_i, b} = R_{\theta_i, a+b}$，当位置 $m$ 的查询与位置 $n$ 的键算内积时，绝对位置奇迹般地相消成纯粹的相对位移 $n - m$：

$$
(R_{\theta, m} q)^T (R_{\theta, n} k) = q^T R_{\theta, m}^T R_{\theta, n} k = q^T R_{\theta, n - m} k
$$

图 2 用交互圆盘与多频率热力图把这一不变性可视化：无论词对位于句首 `(m=2, n=5)` 还是整体后移至 `(m=19, n=22)`，只要间距不变，夹角与点积便严丝合缝。同时可以看到最快通道 $\theta_0 = 1.0\;\text{rad/token}$ 捕捉近邻词序，最慢通道 $\theta_3 = 0.001\;\text{rad/token}$ 承载远距离依赖。

生产代码里真正容易踩坑的，不是三角函数公式，而是**哪两个通道配成一对二维平面**：

- **NeoX 跨半段配对（`rotate_neox`）**：vLLM 默认路线[^vllm_rope_common]，把第 `i` 维与第 `i + d/2` 维配成对（如 `(x_0, x_4)`），用 `[-x_{d/2:}, x_{:d/2}]` 就能向量化算出正交旋转，不打散连续访存对齐。
- **GPT-J / DeepSeek-V3 相邻交错配对（`rotate_gptj`）**：相邻偶奇维 `(x_{2i}, x_{2i+1})` 直接配成复数实部和虚部[^vllm_rope_common][^ds_rope]，DeepSeek-V3 参考代码直接用 `torch.view_as_complex` 做复数乘法实现。只要初始化加载权重时按索引置换重排一次 `Q/K` 投影行，两种写法数值**逐位等价**。
- **DeepSeek-V4 尾切片与可逆旋转**：vLLM 标准层只切片前 `rotary_dim` 维（`:rotary_dim`）旋转[^vllm_rope_base]；但 `DeepseekV4ScalingRotaryEmbedding` 把不旋转的语义维度放在前头，专门切片**末尾** `rotary_dim` 通道做旋转（偏移量 `rope_dim_offset = head_size - rotary_dim`），同时全程保留 `float32` 正余弦表、支持 `key=None` 单输入，并额外提供 `inverse=True` 对 `sin` 取反把向量旋回原坐标[^vllm_dsv4_rope]。在模型配置入口 `build_deepseek_v4_rope` 中，全注意力 `"main"` 分支走 YaRN，局部滑动窗口 `"compress"` 分支固定回退 `factor=1.0` 普通 RoPE 且显式关闭 `mscale`[^vllm_dsv4_builder]。

## 长上下文外推与 YaRN：为什么不能把频率一刀切

如果模型训练时只见过最大长度 $L = 4096$，推理硬塞进 `32K` 或 `128K` 文本，低频端会出现训练期从未见过的夹角，注意力瞬间崩溃。怎么把 $L$ 温和撑大 $s$ 倍（如 DeepSeek-V3 从 `4K` 外推到 `128K` 时取缩放因子 $s = 40$[^ds2412_yarn]）？历史上有两条过渡方案和最终的 **YaRN**：

1. **线性位置插值（PI）**：把所有位置压缩为 $m / s$（等效所有频率同乘 $1/s$）。缺陷是连原本转得很快的高频近邻通道也被除以 40，相邻两个字的夹角变得紧挨在一起、局部词序变糊。
2. **NTK-Aware 缩放**：按比例抬高公式里的基数 $\text{base}$，让高频少动、低频拉慢，但各维度缩放仍被单调公式死锁，边界维度往往微调不足。
3. **YaRN（Yet another RoPE extensioN）**：Peng 等人在 2023 年直接按「在训练长度 $L$ 内转了多少整圈」来精确划分频段[^peng2023]。

设第 $i$ 对通道的波长为 $\lambda_i = 2\pi / \theta_i = 2\pi \cdot \text{base}^{2i/d}$，它在原训练窗口 $L$ 内完整转过的圈数为 $r_i = L / \lambda_i$。设高频阈值 $\beta_{\text{fast}} = 32$、低频阈值 $\beta_{\text{slow}} = 1$，算出斜坡掩码与外推保留系数 $\text{extrap}_i = 1 - \text{ramp}_i$，最终有效频率与温度补偿为[^vllm_rope_yarn]：

$$
\theta'_i = (1 - \text{extrap}_i) \cdot \frac{\theta_i}{s} + \text{extrap}_i \cdot \theta_i, \qquad \text{mscale} = 0.1 \ln(s) + 1.0
$$

对照图 3 三条频段看数值边界（以 `rotary_dim=64`、$L=4096$、$s=40$ 为例）：

- **高频短波段（`i <= 10`，圈数 $> 32$）**：在 4K 训练窗内已来回转过三十多圈，早就被训练得极其充分。令 $\text{extrap}_0 = 1.0$，完全保留原始频率 $\theta_i$，紧邻词元的相位分辨力一分不动。
- **中频斜坡过渡区（`10 < i < 23`，圈数介于 `1` 与 `32` 之间）**：通过 `yarn_linear_ramp_mask` 在高频与低频之间线性过渡，避免频谱在交界处突变跳变。
- **低频长波段（`i >= 23`，圈数 $< 1$）**：连完整一圈都没转完过的长波长维度直接执行安全线性插值 $\theta_i / s$（$\text{extrap} = 0.0$），平稳撑开全局视野。
- **温度补偿 `mscale`**：拉长序列并改频谱后，点积方差与注意力熵会轻微发散。YaRN 用 $\text{mscale} = 0.1\ln(s) + 1$ 收紧温度；当 $s = 40$ 时算出 `mscale = 1.3689`，DeepSeek-V3 在 `MLA` 初始化中把注意力缩放因数额外乘以 `mscale * mscale = 1.8739`（详见[系列三 DeepSeek 01：MLA](../../deepseek/01-mla/)），相当于只修正 $q \cdot k$ 温度而不用修改 $Q$ 和 $K$ 向量本身[^ds_mla_scale]。

## NumPy 核心实现与双硬件源码对照

下面的独立 NumPy 脚本同时复现图 1 的 4 词元因果注意力权重与输出、图 2 的 RoPE 相对距离严格不变性，以及图 3 的 `mscale^2 = 1.8739` 温度系数：

```python
import math
import numpy as np

Q = np.array([[1.0, 0.5, 0, 0], [0.5, 1.0, 0.5, 0], [0.5, 1.0, 0.5, 1.0], [1.0, 0.5, 0.5, 1.0]])
K = 2.0 * np.eye(4)
V = np.array([[1.0, 0, 0.5, 0], [0, 1.0, 0, 0.5], [0.5, 0.5, 1.0, 0], [0, 0, 0.5, 1.0]])
S = (Q @ K.T) / math.sqrt(4) + np.triu(np.full((4, 4), -np.inf), k=1)
P = np.exp(S - np.max(S, axis=-1, keepdims=True))
P /= np.sum(P, axis=-1, keepdims=True)
O = P @ V
assert O.shape == (4, 4) and np.allclose(P.sum(axis=-1), 1.0)
print("t=2 weights:", np.round(P[2], 4), "-> O_2:", np.round(O[2], 4))
print("t=3 weights:", np.round(P[3], 4), "-> O_3:", np.round(O[3], 4))

def rope_neox(x, pos, freqs):
    ang = pos[:, None] * freqs[None, :]
    cos = np.concatenate([np.cos(ang), np.cos(ang)], axis=-1)
    sin = np.concatenate([np.sin(ang), np.sin(ang)], axis=-1)
    d2 = x.shape[-1] // 2
    return x * cos + np.concatenate([-x[..., d2:], x[..., :d2]], axis=-1) * sin

freqs = 10000.0 ** (-np.arange(0, 8, 2) / 8)
q_b = np.array([[1.2, -0.4, 0.8, 0.3, -0.6, 1.1, 0.2, -0.5]])
k_b = np.array([[-0.5, 0.9, 0.4, -1.1, 0.7, 0.2, -0.8, 0.6]])
d1 = float((rope_neox(q_b, np.array([2]), freqs) * rope_neox(k_b, np.array([5]), freqs)).sum())
d2 = float((rope_neox(q_b, np.array([19]), freqs) * rope_neox(k_b, np.array([22]), freqs)).sum())
assert abs(d1 - d2) < 1e-12
print(f"RoPE dot(2,5)={d1:.6f} == dot(19,22)={d2:.6f}, mscale^2={(0.1 * math.log(40.0) + 1.0) ** 2:.4f}")
```

## 代价与边界

1. **标准自注意力的显存与算力随序列长 $T$ 二次方膨胀**：虽然这里只推导了 4 词元算术，但完整 $QK^T$ 矩阵占 `O(T^2)` 计算与中间存储；到了工业级解码阶段，如果每次生成新词都重复重算所有历史 $K$ 和 $V$，带宽成本会彻底失控——这也是为什么要引入 **KV Cache**。
2. **YaRN 的无感外推存在倍增与领域边界**：经验表明，在原长 `4K` 模型上借助 YaRN 做短期微调可将窗口平滑扩展至 `32K` 到 `128K`，但若未经继续预训练直接零样本硬拉几十倍，或者在局部精确检索密集的代码任务中 `s` 过大导致中频混叠，精度仍会出现回落；而 DeepSeek-V4 在滑动窗口分支故意设 `factor=1.0` 不缩放，正是为了隔离局部窗口与全局窗口的失真。
3. **跨框架迁移必须核对 RoPE 配对规范与切片位置**：把训练权重搬运到推理引擎时，哪怕三角公式写得完全正确，只要搞反 `is_neox_style`（前/后半段 vs 奇/偶相邻）或切片位置（头切片 `:rotary_dim` vs 尾切片 `-rotary_dim:`），模型的困惑度（PPL）就会立刻炸裂成乱码。
