前两章划清了单卡前向的计算类型与双硬件微架构约束，其中 RMSNorm 与 SwiGLU 都在单个 token 内部独立完成。把“猫 坐在 垫 上”打乱成“上 垫 坐在 猫”，第 3 号向量独自穿过前馈网络后产出依然不变。只靠逐位置运算，语言模型就无法在前后词之间交换语义。

**Self-Attention（自注意力）**打通了序列内部的横向信息流，让当前 token 按内容相关性加权聚合历史信息。**RoPE（Rotary Position Embedding，旋转位置编码）**通过二维正交旋转把绝对坐标折叠进点积里的相对位移。**YaRN（Yet another RoPE extensioN，长上下文分频外推）**则在拉长上下文窗口时按频段分层缩放旋转角，防止注意力分布失焦。

## 因果自注意力检索与数值计算

可以把自注意力看作一次向量检索，每个 token 同时投影出三个向量。其中 **Query（查询，$Q$）**代表当前寻找的目标，**Key（键，$K$）**挂在身上供他人匹配，**Value（值，$V$）**则是匹配后被加权取走的内容。

考虑由 4 个 token 组成的短句 `["猫", "坐在", "垫", "上"]`（位置索引 $t = 0, 1, 2, 3$），设单头特征维度 $d_k = 4$（缩放因子 $\sqrt{d_k} = 2$）。为便于直观验证缩放点积，我们构造键矩阵 $K = 2 I_4$（四行依次为单位阵乘 2），取查询行 $q_2 = [0.5, 1.0, 0.5, 1.0]$、$q_3 = [1.0, 0.5, 0.5, 1.0]$。同时设值矩阵四行为 $v_0 = [1.0, 0, 0.5, 0]$、$v_1 = [0, 1.0, 0, 0.5]$、$v_2 = [0.5, 0.5, 1.0, 0]$、$v_3 = [0, 0, 0.5, 1.0]$，图 1 步进演示了这组张量的打分、掩码、归一化与输出聚合过程。

因为特意选取了 $K = 2 I_4$，除以 $\sqrt{4} = 2$ 后恰好有 $Q K^\top / 2 = Q$，于是第 $t=2$ 行（“垫”）对四个位置的缩放打分无需计算内积就能直接读出为 $q_2 = [0.5, 1.0, 0.5, 1.0]$。其中末位得分 1.0 来自尚未生成的未来位置 $t=3$（“上”）；若直接做归一化，生成模型就会读取到未来的 token。

为了保持单向因果性，在送入 Softmax 之前，必须在主对角线上方（所有行号小于列号的未来单元）加上因果掩码矩阵 $M_{\text{triu}}$（未来单元置为 $-\infty$，其余为 0），将 $t=2$ 行的分数变为 $[0.5, 1.0, 0.5, -\infty]$。随后逐行做 Softmax 归一化，由于 $e^{-\infty} = 0$，未来权重归零。

此时 $t=2$ 行权重为 $[0.2741, 0.4519, 0.2741, 0.0000]$（重点落在 $t=1$“坐在”上），而处于句尾的 $t=3$ 行可以看全 4 个词，权重为 $[0.3112, 0.1888, 0.1888, 0.3112]$，同时锚定句首主语“猫”和自身“上”。

最后按 $O = P V$ 对四行值向量加权求和，得到 $O_2 = [0.4111, 0.5889, 0.4111, 0.2259]$ 与 $O_3 = [0.4056, 0.2832, 0.5000, 0.4056]$。经过这一层聚合，末尾位置的表征已经融合了句首主语的上下文信息。

## 因果多头自注意力与缩放因子

将上述 4 个 token 的运算写成一般张量形式，先确定符号定义与形状：

| 符号              | 含义                                           | 张量形状   | 所在角色                                  |
| :---------------- | :--------------------------------------------- | :--------- | :---------------------------------------- |
| $T$               | 序列长度（上例中 $T = 4$）                     | 标量       | 输入 token 数                             |
| $H,\,d_k$         | 注意力头数与单头维度                           | 标量       | 多头划分 $d_{\text{model}} = H \cdot d_k$ |
| $Q,\,K,\,V$       | 查询、键、值矩阵（单头切片）                   | `[T, d_k]` | 线性投影输出                              |
| $M_{\text{triu}}$ | 因果掩码（上三角未来位为 $-\infty$，其余为 0） | `[T, T]`   | 阻断未来信息泄露[^ds_causal]              |

单头缩放点积因果自注意力的计算公式为[^vaswani2017]：

$$
\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}} + M_{\text{triu}}\right) V
$$

分母上的 $\sqrt{d_k}$ 用于抵消点积方差随特征维度 $d_k$ 的线性放大。假定 $q$ 和 $k$ 的各分量彼此独立，且均值为 0、方差为 1，则单维乘积 $q_j k_j$ 的方差为 $\operatorname{Var}(q_j k_j) = \mathbb{E}[q_j^2]\mathbb{E}[k_j^2] = 1$；把 $d_k$ 个独立项相加后，未缩放点积的方差膨胀为 $d_k$：

$$
\begin{aligned}
\operatorname{Var}(q \cdot k) &= \sum_{j=1}^{d_k} \operatorname{Var}(q_j k_j) = d_k \\
\Longrightarrow\quad \operatorname{Var}\!\left(\frac{q \cdot k}{\sqrt{d_k}}\right) &= \frac{d_k}{(\sqrt{d_k})^2} = 1
\end{aligned}
$$

在主流大模型中，$d_k$ 往往取 64 或 128。若不除以 $\sqrt{d_k}$，原始内积的典型波动幅度会扩至 $\pm\sqrt{64} = \pm 8$ 甚至更大；指数函数会把领先几分的位置压成接近 `[1.0, 0.0, 0.0, ...]` 的尖峰分布，导致其余位置的梯度接近于零而难以训练。乘以 $1/\sqrt{d_k}$ 恰好把 Softmax 输入方差拉回稳定的 1.0，在 vLLM 的注意力实现中对应缩放系数 `self.scaling = self.head_dim**-0.5`[^vllm_dsv2_attn]。

如果整句话只用一套 $Q/K$ 打分，就像图书检索只允许按单一种指标排序，很难同时兼顾主谓搭配、代词指代和标点边界。**MHA（Multi-Head Attention，多头注意力）**将总维度 $d_{\text{model}}$ 拆成 $H$ 组独立的 `[T, d_k]` 子空间，并行计算注意力与加权求和。随后沿最后一维拼回 `[T, H * d_k]` 并乘以输出投影矩阵 $W_O$，让不同头各自捕捉不同粒度的语义关联。

## 旋转位置编码与通道布局等价性

仅靠点积和加权求和，自注意力依然具有**置换等变性**：同时打乱输入行的顺序，输出也只是跟着换位置，模型分不清谁紧挨着谁。Su 等人在 2021 年提出的 RoPE[^su2021] 按位置 $m$ 对 $Q$ 和 $K$ 施加二维正交旋转，不再把位置向量直接加到输入嵌入上，从而把位置信息直接编入注意力内积的相位差里。

在二维平面上取一对通道 $(x_0, x_1)$，让位置 $m$ 的向量转过角度 $m\theta_i$，旋转矩阵 $R_{\theta_i, m}$ 与随维度索引 $i$ 指数衰减的角频率 $\theta_i$ 定义如下：

$$
\begin{aligned}
R_{\theta_i, m} &= \begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix} \\
\theta_i &= \text{base}^{-2i/d},\quad i \in \left\{0, 1, \dots, \frac{d}{2}-1\right\}
\end{aligned}
$$

二维旋转矩阵是正交矩阵，满足转置即逆角 $R_{\theta_i, m}^\top = R_{\theta_i, -m}$ 且旋转角可加 $R_{\theta_i, a} R_{\theta_i, b} = R_{\theta_i, a+b}$。因此位置 $m$ 的查询与位置 $n$ 的键算内积时，绝对位置坐标在正交乘法中直接消去，点积仅取决于两者的相对距离 $n - m$：

$$
(R_{\theta, m} q)^\top (R_{\theta, n} k) = q^\top R_{\theta, m}^\top R_{\theta, n} k = q^\top R_{\theta, n - m} k
$$

图 2 从几何圆周和频谱相位两方面演示了这一相对不变性。当词对从 $(m=2, n=5)$ 平移至 $(m=19, n=22)$ 时，两个向量在圆周上同步转过 $17\;\text{rad}$（约 $2.71$ 圈），夹角与全 8 维点积（$0.668685$）保持相等。高频通道 $\theta_0 = 1.0\;\text{rad/token}$ 紧盯近邻词序，低频通道 $\theta_3 = 0.001\;\text{rad/token}$ 则跨越上千位置缓慢旋转以承载远距离依赖。

<RopeRotationExplainer client:visible title="图 2：RoPE 二维旋转相对不变性与多通道角频率衰减机制" />

工程落地时，公式之外最容易出岔子的是**哪两个通道配成一对二维平面**，以及**只旋转部分维度时切片落在哪一段**。

开源框架在通道配对上常见两种内存布局。`vLLM` 默认采用 NeoX 风格（`rotate_neox`），把前半段第 $i$ 维与后半段第 $i + d/2$ 维配对，按 `[-x_{d/2:}, x_{:d/2}]` 向量化计算即可保持半段连续访存[^vllm_rope_common]。GPT-J 风格则采用交错配对（`rotate_gptj`），把相邻偶奇维 $(x_{2i}, x_{2i+1})$ 当作复数实部和虚部旋转[^vllm_rope_common][^ds_rope]。

这两种布局在数学上只是对 $d$ 个特征通道做了一次固定置换。只要在权重加载阶段同步重排投影矩阵的输出行顺序，NeoX 与 GPT-J 算出的旋转内积逐位等价。

在 **Partial RoPE（部分维度旋转，即 $d_{\text{rotary}} < d_{\text{head}}$）**场景下，头内只有部分通道参与旋转，其余保留纯内容特征。标准实现通常旋转前部切片 `:rotary_dim`[^vllm_rope_base]，也有架构只旋转末尾 `-rotary_dim:` 区间（向 Kernel 传入偏移量 `head_size - rotary_dim`）[^vllm_dsv4_rope]。无论选哪一段，权重切分与运行时 RoPE 算子的切片都必须对齐，否则注意力分数就会退化成乱码。

## 长上下文外推与 YaRN 分频缩放

如果模型预训练窗口只有 $L = 4096$，推理直接送入 32K 或 128K 序列时，低频通道会遇到未见过的相位角，导致注意力打分失真。为了把窗口扩到 $s$ 倍（如 DeepSeek-V3 从 4K 延展到 128K 时取 $s = 40$[^ds2412_yarn]），早期出现了两种平滑缩放方案。

**PI（Position Interpolation，线性位置插值）**把所有位置同除以 $s$，连高频近邻通道也跟着缩小 40 倍，导致相邻字旋转角挤成一团、损害局部语序分辨。**NTK-Aware（Neural Tangent Kernel 感知）**通过抬高底数 $\text{base}$ 减缓高频压缩，但所有频率仍受单调曲线耦合，中低频边界往往补偿不足。

**YaRN（Yet another RoPE extensioN）**[^peng2023] 改按“在原始训练窗口 $L$ 内到底转过多少整圈”来精确划分频段。第 $i$ 对通道的波长为 $\lambda_i = 2\pi / \theta_i = 2\pi \cdot \text{base}^{2i/d}$，它在原训练窗口 $L$ 内转过的圈数为 $r_i = L / \lambda_i$。设定高频整圈阈值 $\beta_{\text{fast}} = 32$ 与低频整圈阈值 $\beta_{\text{slow}} = 1$，把两道阈值映射回通道对索引下界 $\text{low}$ 与上界 $\text{high}$（在 $d_{\text{rotary}} = 64$、$L = 4096$、$\text{base} = 10000$ 时算出 $\text{low} = 10$、$\text{high} = 23$），即可定义分段斜坡函数 $\text{ramp}_i$ 与外推保留系数 $\text{extrap}_i$[^vllm_rope_yarn]：

$$
\begin{aligned}
\text{ramp}_i &= \operatorname{clip}\!\left(\frac{i - \text{low}}{\text{high} - \text{low}},\ 0,\ 1\right) \\
\text{extrap}_i &= 1 - \text{ramp}_i
\end{aligned}
$$

利用这组分段系数，将需要插值的低频项 $\theta_i / s$ 与保持原速的高频项 $\theta_i$ 平滑混合，并配合对数温度补偿系数 $\text{mscale}$[^peng2023][^vllm_rope_yarn]：

$$
\begin{aligned}
\theta'_i &= (1 - \text{extrap}_i) \cdot \frac{\theta_i}{s} + \text{extrap}_i \cdot \theta_i \\
\text{mscale} &= 0.1 \ln(s) + 1.0
\end{aligned}
$$

拉长序列并改写频谱后，点积方差和注意力熵往往会轻微发散。如果在生成旋转表时把 $\cos$ 与 $\sin$ 同乘 $\text{mscale}$，等价于同时把旋转后的 $Q$ 与 $K$ 各自放大 $\text{mscale}$ 倍；展开点积即可看出，这与保持 $Q, K$ 幅值不变、只把注意力的缩放系数乘以 $\text{mscale}^2$ 完全等价：

$$
\frac{(\text{mscale} \cdot q)^\top (\text{mscale} \cdot k)}{\sqrt{d_k}} = \left(\frac{\text{mscale}^2}{\sqrt{d_k}}\right) q^\top k
$$

在 $s = 40$ 时算得 $\text{mscale} = 1.3689$，因此推理框架也可以选择把 $\text{mscale}^2 \approx 1.8739$ 直接合入注意力的 `softmax_scale` 标量里[^ds_mla_scale]。图 3 展示了 32 对旋转通道在 4K 原生窗、PI 均匀插值与 YaRN 三频段斜坡之间的频谱差异，以及 GPU 与昇腾侧频率表的排布方式。

![YaRN 分频斜坡外推对比 4K 原生与 PI 均匀插值，展示高频、斜坡与低频分段，以及 vLLM GPU 与 vllm-ascend 的频率 Cache 排布差异](./diagrams/03-yarn-spectrum.drawio '图 3：YaRN 分频斜坡外推（low=10, high=23）、mscale 修正与 GPU/昇腾缓存排布')

对照图 3 的 32 对通道可以看到三段分工。索引 $i \le 10$ 的高频短波段在 4K 训练窗内已转过超过 32 圈，相位训练充分，因此取 $\text{extrap}_i = 1.0$ 保留原频率，不损近邻语序。索引 $i \ge 23$ 的低频长波段在原窗内不足一圈，需取 $\text{extrap}_i = 0.0$ 缩放到 $\theta_i / s$，撑开长距离表征。

中间 $10 < i < 23$ 的过渡区沿斜坡函数线性衔接，避免频谱在边界发生突变。若未经长序列继续预训练就把 $s$ 零样本拉高几十倍，YaRN 在中频检索上仍会出现衰减；而只看局部近邻的滑动窗口注意力层会锁定 `factor = 1.0`，保持原生频率不外推。

## NumPy 验证与双硬件源码对照

下面的自包含 NumPy 脚本同时验证图 1 的 4-token 因果注意力权重与输出、图 2 的 RoPE 相对距离不变性，以及图 3 中 $s = 40$ 时的 $\text{mscale}^2 = 1.8739$ 数值：

```python
import math
import numpy as np

Q = np.array([
    [1.0, 0.5, 0, 0],
    [0.5, 1.0, 0.5, 0],
    [0.5, 1.0, 0.5, 1.0],
    [1.0, 0.5, 0.5, 1.0],
])
K = 2.0 * np.eye(4)
V = np.array([
    [1.0, 0, 0.5, 0],
    [0, 1.0, 0, 0.5],
    [0.5, 0.5, 1.0, 0],
    [0, 0, 0.5, 1.0],
])
mask = np.triu(np.full((4, 4), -np.inf), k=1)
S = (Q @ K.T) / math.sqrt(4) + mask
P = np.exp(S - np.max(S, axis=-1, keepdims=True))
P /= np.sum(P, axis=-1, keepdims=True)
O = P @ V
assert O.shape == (4, 4) and np.allclose(P.sum(axis=-1), 1.0)
print("t=2 weights:", np.round(P[2], 4), "-> O_2:", np.round(O[2], 4))
print("t=3 weights:", np.round(P[3], 4), "-> O_3:", np.round(O[3], 4))

def rope_neox(x, pos, freqs):
    ang = pos[:, None] * freqs[None, :]
    cos = np.concatenate([np.cos(ang), np.cos(ang)], axis=-1)
    sin = np.concatenate([np.sin(ang), np.sin(ang)], axis=-1)
    d2 = x.shape[-1] // 2
    x_rot = np.concatenate([-x[..., d2:], x[..., :d2]], axis=-1)
    return x * cos + x_rot * sin

freqs = 10000.0 ** (-np.arange(0, 8, 2) / 8)
q_b = np.array([[1.2, -0.4, 0.8, 0.3, -0.6, 1.1, 0.2, -0.5]])
k_b = np.array([[-0.5, 0.9, 0.4, -1.1, 0.7, 0.2, -0.8, 0.6]])
d1 = float(
    (rope_neox(q_b, np.array([2]), freqs)
     * rope_neox(k_b, np.array([5]), freqs)).sum()
)
d2 = float(
    (rope_neox(q_b, np.array([19]), freqs)
     * rope_neox(k_b, np.array([22]), freqs)).sum()
)
assert abs(d1 - d2) < 1e-12
mscale_sq = (0.1 * math.log(40.0) + 1.0) ** 2
print(f"RoPE dot(2,5)={d1:.6f} == dot(19,22)={d2:.6f}, mscale^2={mscale_sq:.4f}")
```

| 交错适配 | 传入 `interleaved` 原地计算 | 转置 `(d//2, 2)` 走 NeoX 通路 | 避开交错 3D 视图片上开销 |
| 片上分块 | 依赖寄存器与 SMEM           | 按 192 KB UB 估算最大头数块   | 防止 FP32 中间态触发溢出 |

围绕[第 02 章](../02-gpu-and-ascend-architecture/)拆解的硬件约束，`vllm-ascend` 做了两处关键适配。第一处面向 GPT-J 交错布局，因为昇腾底层的 `npu_rotary_embedding` 偏好连续半段读取。遇到 `is_neox_style=False` 时，`AscendDeepseekScalingRotaryEmbedding` 先重塑为 `(d//2, 2)` 并转置成连续半段，再走高速通路完成旋转[^ascend_rope]。

由于 $Q$ 与 $K$ 经历了相同的正交通道置换，且两者在注意力里只做内积而不混入 $V$，内积结果对共同置换保持不变。因此这里免去了再转置还原的拷贝开销；若下游算子依赖原通道顺序，再执行一次逆转置即可复原。

第二处是片上 **UB（Unified Buffer，片上统一缓存）**容量控制。在 Triton 旋转 Kernel 中，调度函数会统计峰值常驻的 `float32` 张量数：NeoX 路径为 8 个半宽张量，3D 交错路径为 10 个全宽张量。算子再按 192 KB `UB` 的 50% 余量反推最大头分块[^ascend_triton_rope]。同时，常用频率表会预建连续交错视图与固定地址缓冲，既免去逐次索引触发全表拷贝，也保证了静态图重放的指针稳定[^ascend_rope]。

到这里为止，刚才的 4-token 计算示例里还有一笔关键开销没有展开。生成第 $T + 1$ 个 token 时，前面 $T$ 个历史 token 的 $K$、$V$ 向量与上一步完全相同，每次重算全前缀会浪费大量算力。下一章[04 KV Cache 与 MQA / GQA](../04-kv-cache-and-gqa/)就来拆解历史键值的缓存复用，以及在显存与头数之间做折中的 MQA 和 GQA。
