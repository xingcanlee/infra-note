Wisp 指的是一缕细烟，也指一丝很淡的痕迹。给这个主题起这个名字，是希望它像一缕细烟一样轻：页面里只留下文字，其余的东西尽量退到背后。

## 为什么做这个主题

很多技术博客的模板功能很多，但阅读体验并不好。标题层级靠厚重的分隔线区分，正文行宽过长，代码块和正文抢颜色，中英文之间的间距全靠手动加空格。Wisp 想做的事情很少：

- 让正文好读，行高和行宽按中文的习惯来设定。
- 让层级靠字号、字重和留白来体现，而不是靠边框和阴影。
- 让图表、公式和代码在同一套颜色体系下出现。

## 设计取向

主题的关键词是**安静、好读、克制**。整站只有一个强调色，它用于链接和焦点状态。图表和代码里会出现更多颜色，但它们也都来自同一份令牌文件，所以明暗两种主题切换时不会错位。

> 好的排版不需要被注意到，读者只需要顺着文字往下走。

这句话是设计时反复提醒自己的一条原则。

## 写作方式

每篇文章是一个目录，里面放 `index.md` 或 `index.mdx`，图表源文件放在 `diagrams/` 子目录中。也支持单文件形式，例如 `posts/some-note.md`。文章开头的 frontmatter 决定标题、摘要、日期、标签和分类：

```yaml
title: "欢迎来到 Wisp"
description: "一段不超过 200 字的摘要"
pubDate: 2026-01-12
tags: [Wisp, Astro]
category: 随笔
featured: true
```

`featured` 为 `true` 的文章会出现在首页的精选区。`draft` 为 `true` 的文章只在开发环境中可见，生产构建时会被过滤掉。

## 功能一览

| 功能 | 说明 |
|---|---|
| 数学公式 | 行内公式如 $E = mc^2$，块级公式基于 KaTeX 渲染 |
| 流程图 | Mermaid 代码块在构建期渲染为内联 SVG，页面里不需要 Mermaid 的运行时 |
| 图表 | 支持 Excalidraw 和 draw.io 源文件，导出可移植的 SVG，并提供源文件下载 |
| 交互讲解 | 用 React island 实现的逐步演示，只在需要它的文章中加载 |
| 代码高亮 | Shiki 双主题，可选行号和复制按钮 |
| 目录 | 宽屏时放在右侧，窄屏时折叠在文首 |

## 站点结构

首页展示精选文章和最新列表。文章按年份归档，标签和分类各自有独立的页面，标签名中的中文会保留原样，例如 `#注意力`。站点还提供 RSS 订阅和 Sitemap，方便被搜索引擎和阅读器收录。

这个主题的目标读者是需要写技术文章、但不想花太多时间折腾样式的人。如果你只关心文字，这个主题应该够用了。[^1]

[^1]: 主题的更多配置项见站点配置文件 `wisp.config.ts`。配置经过 zod 校验，缺省项会自动使用默认值。
