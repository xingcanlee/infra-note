infra-note 是一份围绕 LLM 推理基础设施的技术笔记：关注模型如何被编译成计算图、如何下沉到内核与设备执行，以及运行时怎样调度、缓存和排错。

目前最完整的一组文章是 vLLM 图模式系列，从 CUDA Graph 讲到 Ascend ACLGraph；后续内容会继续扩展到推理引擎、编译器、并行策略和性能分析等方向。

## 阅读路线

推荐先阅读推理流程与提交开销，再按顺序了解编译图、CUDA Graph、vLLM dispatcher，最后进入 Ascend 的实现与排错。没有设备时，可以先运行纯 Python 练习，建立图桶、padding 和模式回退的直觉。

## 内容边界

文中的源码分析固定在文章注明的提交附近，不代表当前版本的完整兼容矩阵。没有 GPU 或 NPU 时，捕获、重放和性能收益只能作为机制分析，不能替代目标硬件上的正确性检查与 profiler 证据。
