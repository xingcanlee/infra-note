# Wisp 图表布局规则

颜色、字号、线宽的硬规则见 SKILL.md；这里只讲**怎么摆**。目标：一眼读懂、安静、和正文排版一致。

## 1. 网格与尺寸

- 所有节点的 `x / y / w / h` 取 8 的倍数（lint 会对不在 8px 网格上的元素给出 `grid` 警告）。
- 常用节点尺寸（宽 × 高）：短标签 96×48；常规 128×56 / 144×56；两行标签 160×64；强调节点可以更大，不要超过 192×96。
- 节点横向间距 ≥ 64，纵向间距 ≥ 32；**要在连线上放标签时，间距 ≥ 96**。
- 画布整体从 (0, 0) 附近开始即可，导出时会自动裁边；不需要画背景矩形。

## 2. 留白与对齐

- 同一行/同一列的节点中心对齐（y 或 x 相同），不要靠肉眼错开几像素。
- 组与组之间的留白大于组内节点的间距（至少 1.5 倍），靠留白而不是靠边框分组。
- 标题与内容之间至少留 32px；注释与内容之间至少留 32px。
- 一张图的主流向只有一个：从左到右，或从上到下（Transformer 这类堆叠结构自下而上也可以，但要全图一致）。

## 3. 箭头路由

- Excalidraw 骨架的箭头是两节点中心连线上的**直线**：不会自动绕路。摆放节点时让连线不穿过第三个节点；做不到就调整布局，或改用 draw.io。
- 不要出现交叉的连线；必须交叉时让它们垂直相交，不要斜交。
- 一个节点同时有多条出线/入线时，把目标节点沿纵向均匀排开（扇出），例如 X → Q/K/V。
- 反馈、残差、循环用**虚线**，颜色用 muted（灰）或语义色（残差、梯度用玫红）。
- 箭头标签 ≤ 6 个汉字或 12 个字符；放在较长的线段上。太短的线段不要加标签（标签会压住箭头头部）。
- draw.io 中用 `edgeStyle=orthogonalEdgeStyle` 的直角折线，拐点落在 8px 网格上。

## 4. 分组框

- 分组框用浅灰填充（surface）+ 浅灰虚线边（border），标签放在左上角，字号 12，颜色 muted。
- 分组框内边距 ≥ 24；不要嵌套超过两层。
- 分组框不要使用 hue 色（避免和语义色混淆），也不要加阴影。
- Excalidraw 骨架里用 `color: "muted"`、`dashed: true` 的大矩形表示分组框；注意它的 label 会居中，需要左上角标签时用单独的 `texts` 条目。

## 5. 标题与注释

- 标题：18px，放在图的左上角，左对齐，与内容左边缘对齐。一张图一个标题；文章正文里的图可省略标题，由 `<figcaption>` 承担。
- **骨架里写一个 `size: "title"` 的独立文本**：build 会把它作为 SVG 的 `<title>`，其余文字拼成 `<desc>`，这是无障碍文本的来源。
- 注释：12px，muted 色，放在图的左下角，以“注：”开头，一句话讲完。

## 6. 信息密度

- 一张图只讲一件事。节点数建议 ≤ 12，超过就拆成两张图，或者把细节折叠成一个节点。
- 每个节点一个概念，标签是名词或短语，不写句子。
- 用颜色表达语义（Q/K/V/权重…），不要为了好看给同类节点换色。同一篇文章里同一语义始终同一个 hue。
- 强调只用一处（线宽 2.5），通常是最终输出或要讲解的关键节点。

## 7. 中文标签

- 字号 14 时，**每行不超过 8–10 个汉字**；超过就换行（骨架里用 `\n`，draw.io 里用 `&lt;br&gt;`）。
- 节点宽度 ≈ 汉字数 × 14 + 32：6 个字约 120→128，8 个字约 144→160。
- 中英混排时中英文之间留一个空格（`多头注意力 MHA`）；公式和符号（Q·Kᵀ/√d）保持原样，不拆行。
- 手绘风格（Excalidraw）中文回落到 Noto Sans SC，不使用小赖体；不要靠加粗/斜体强调中文。
- 标签文字、描边使用同一个 hue 的 stroke 色（骨架默认如此），保证在 light/dark 下都有 ≥ 4.5:1 对比度。

## 8. 手绘（hand）与规整（clean）怎么选

| | hand（Excalidraw） | clean（draw.io） |
|---|---|---|
| 适合 | 概念、直觉、流程示意 | 精确结构、层次、对齐要求高 |
| 节点数 | ≤ 12 | 可更多 |
| 连线 | 直线 | 直角折线、曲线 |
| 同一篇文章 | 风格尽量统一，不要两种混用在同一张图里 | |
