draw.io 自定义调色板配置（让作者只能选到 Wisp 调色板里的颜色）

文件：同目录下的 drawio-config.json（纯 JSON，内容由 palette.json 的浅色令牌生成）。

使用步骤（draw.io 网页版或桌面版）：
1. 菜单 Extras（其他） → Configuration（配置）。
2. 把 drawio-config.json 的全部内容粘贴进对话框，点击 Apply，然后刷新页面。
   桌面版也可以改为设置环境变量 DRAWIO_CONFIG（内容为同一段 JSON）。
3. 导入图形库：File → Open Library from → Device，选择 wisp-drawio-library.xml。
4. 新建文件后，在 File → Properties 中取消勾选 Compressed，保证保存的是未压缩 XML。

配置项说明：
- presetColors / defaultColors：颜色选择器中显示的色块，只保留调色板的浅色值（不带 # 的 6 位十六进制）。
- defaultColorSchemes：Format 面板 Style 页中的 8 个 hue 配色方案（描边 + 填充 + 文字色）。
- defaultVertexStyle / defaultEdgeStyle：新建形状和连线的默认样式（圆角 arcSize=8、线宽 1.5、Inter 14px / 12px、无阴影）。
- gridSteps：网格步长 8。

注意：
- 不同版本的 draw.io 对配置项的支持略有差异，不识别的键会被忽略，不影响使用。
- 取色器里仍可手动输入任意十六进制值，所以保存后必须运行 lint 兜底（lint.ts 会报告非调色板颜色，--fix 吸附到最近令牌）。
- 只使用浅色值作画：build 会把它们映射为 var(--wd-*)，暗色主题由 SVG 自动切换，不要在编辑器里手选暗色值。
